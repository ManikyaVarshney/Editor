TN Helper Tool Guide

Type or paste HTML in the dark Wrap text panel. The Preview panel renders the result immediately.

Text formatting

B, I, U, S, E, and ab wrap selected text with bold, italic, underline, strong, emphasis, and strike tags.

X₂ and X² apply subscript and superscript. ⌗ applies a span.

The color controls apply text color or highlight to the current selection.

Paragraph controls align selected content left, center, right, or justified and change indentation.

Lists

Bullet Library offers disc, circle, square, star, diamond, arrow, and checkmark bullets.

Numbering Library offers decimal, alphabetic, Roman, parenthesis, and multilevel numbering.

Choose 1. Normal or 1. Bold before applying a numbered list. The default is normal.

Use the nested bullet or nested number controls when sub-items are needed.

Tables and utilities

Table inserts an m × n table using the row and column fields. More handles row, column, cell, and table changes.

Heading applies Paragraph or Heading 1–6 to selected text.

Find searches and replaces text. Clear All permanently empties the editor. Preitter formats HTML indentation.

SC opens keyboard symbol conversion. The eye button opens shortcut keys.

Shortcut keys

  • Ctrl + B = Bold
  • Ctrl + I = Italic
  • Ctrl + U = Underline
  • Ctrl + Shift + B = Strong
  • Ctrl + Shift + I = Em
  • Ctrl + Shift + S = Span
  • Ctrl + Shift + 8 = Bullet list
  • Ctrl + Shift + 7 = Numbered list
  • Ctrl + Alt + P = Paragraph
  • Ctrl + Alt + 1..6 = H1 to H6
  • Ctrl + Alt + T = Table
  • Ctrl + Enter = BR
  • Ctrl + Shift + Space = Non-breaking space
